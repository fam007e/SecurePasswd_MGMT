Encrypts the database and salt into a single package for mobile synchronization.

This function packs the vault.db and vault.db.salt files together, then encrypts the package using Chacha20-Poly1305 authenticated encryption.

Parameters
db_pathPath to the database file (the salt path is derived from this).
output_bufferBuffer where the encrypted package will be stored.
output_sizePointer to store the size of the generated package.
keyThe 32-byte synchronization key.
Returns
0 on success, -1 on error.
