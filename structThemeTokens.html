Detailed Description

Palette registry for the desktop app.

Each palette provides a dark and a light token set substituted into gui/theme_template.qss. Values are documented in docs/DESIGN_TOKENS.md and mirrored by the Android app (ui/theme/Color.kt). Adding a palette means adding one ThemeTokens pair here — no styling code changes.
