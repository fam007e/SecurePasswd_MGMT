int sync_merge_vaults ( const sync_entry_t * local_entries,
int local_count,
const sync_entry_t * remote_entries,
int remote_count,
const sync_tombstone_t * local_tombstones,
int local_tomb_count,
const sync_tombstone_t * remote_tombstones,
int remote_tomb_count,
sync_merge_report_t * report )

Deterministic, symmetric merge of two vault snapshots.

Identity is (lowercase(service), lowercase(username)). Rules:

  • only on one side -> apply it (unless the other side tombstoned it at or after its updated_at, in which case the deletion wins / entry ignored);
  • identical content -> skip;
  • different content -> the entry with the higher updated_at wins; on a tie the lexicographically larger serialized record wins (side-independent, so both peers converge to the same result). The loser is flagged as a conflict for review UIs, but the winner is always recorded so applying the report keeps both devices consistent.
Returns
0 on success, -1 on error.
